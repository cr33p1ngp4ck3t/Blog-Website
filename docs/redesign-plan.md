# FinAid Hub redesign

Build a bold, useful money publication on the existing Next.js and Sanity stack.

Visual direction: warm paper, near-black typography, orange and acid-lime accents, oversized editorial headlines, offset photography, open article layouts, thin rules, minimal rounded containers. Retain the FinAid Hub identity and financial assistance focus. Support mobile, keyboard navigation, and reduced motion.

- [ ] Repair the shared Sanity client and image builder; keep write credentials on the server.
- [ ] Research current finance discussions and primary sources; create six substantial guides with citations, excerpts, SEO descriptions, and images. Publish only new documents, preserving existing content.
- [ ] Build the magazine homepage, topic filtering, article browsing, accessible search, responsive navigation, and a local savings planner.
- [ ] Apply the design to article and category pages, related reading, about, resources, and contact surfaces.
- [ ] Add canonical metadata, social images, article structured data, robots, RSS, and a complete sitemap.
- [ ] Add focused interaction checks. Run type checks, lint, unit tests, production build, and desktop/mobile browser verification.

No fake subscriber counts, fabricated trends, investment recommendations, newsletter forms without delivery, or paid product deals without evidence. Browser plugin setup is authorized; use Playwright if it cannot be made callable in this session. Image generation is unavailable, so use licensed editorial photographs and native layout graphics.
